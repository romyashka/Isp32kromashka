# ФинУчёт — настольное приложение на C#

## Возможности
- Локальное хранение данных в SQLite.
- Счета: наличные, карта, банк, накопления.
- Доходы и расходы, категории, комментарии и даты.
- Защита от расходной операции на сумму больше доступного баланса.
- Бюджеты на месяц и контроль лимитов.
- Аналитика: расходы по категориям и доли, бюджеты, топ-5 покупок, движение денег по месяцам, отрицательные балансы.
- Автоматический пересчёт балансов.

## Запуск
1. Установите .NET 8 SDK (Windows).
2. Распакуйте архив.
3. Откройте `FinUchet.csproj` в Visual Studio 2022 или Rider.
4. Восстановите NuGet-пакеты и запустите проект (F5).

Либо из папки проекта выполните:
```powershell
dotnet restore
dotnet run
```

## Хранение данных
База создаётся автоматически:
`%LOCALAPPDATA%\FinUchet\finance.db`

При первом запуске создаются профиль «Мой профиль», счёт «Основная карта» с начальным остатком 100 000 ₽ и стандартные категории.

## Примечание о балансе
В приложении начальный остаток счёта хранится как стартовая сумма, а текущий баланс рассчитывается как:
`100 000 + доходы - расходы`.
У каждого счёта сохраняется собственный начальный остаток (`opening_balance`), а текущий баланс рассчитывается как начальный остаток + доходы − расходы.
